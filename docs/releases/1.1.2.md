# Candidate release 1.1.2

The published 1.1.1 archive shipped development tests because its rsync staging
did not use Composer's `.gitattributes` export exclusions. Plugin Check rejected
native filesystem and timezone operations in those test fixtures. This patch
applies the repository's existing development-file exclusions explicitly to the
WordPress archive caller. Runtime code and security redaction are unchanged.

The default pinned WordPress Plugin Check standard and the mandatory archive
check remain enabled. This candidate requires exact-commit hosted QA and a fresh
tag archive check before publication; the historical 1.1.1 tag stays unchanged.
