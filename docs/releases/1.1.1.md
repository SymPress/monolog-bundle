# 1.1.1 release candidate

This patch preserves diagnostic keys such as `bypass`, `tests_passed`, and
`testsPassed`. Their values remain visible in log context and do not become
record-wide text secrets. Exception messages, locations and argument-free traces
retain their diagnostic counts while actual credentials remain masked.

The `pass` shorthand matches key components and common compact credential
aliases. Password, passphrase, token and WordPress session cookie redaction is
preserved, including known short credentials. No handler or configuration changes
are required for this update.

QA, archive and dependency canary calls use the released Workflows 1.2.2 commit
`cd809f3986df3ea617d2d26bdf21ab69cae19c1e`.
