# Monolog Bundle 1.1.3

The profiler handler uses native Monolog handling instead of checking the same
gate again in an extra `handle()` override. Normal direct and Logger calls now
evaluate authorization once before handler processors. Minimum levels, bubbling,
missing-gate rejection and sanitized buffer entries keep their existing behavior.

A Logger with its own processors may make a separate `isHandling()` preflight.
The handler deliberately rechecks after those processors: a processor that
closes the gate cannot reuse the earlier authorization. Decisions are not cached
across records or processing stages.

Regressions exercise real handlers and Logger dispatch, count gate calls, verify
level/bubble behavior and change authorization from a Logger processor. Full PHP
QA and the mandatory production archive review remain release requirements. No
version is implied published by this source release note.
